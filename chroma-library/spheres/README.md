# earth_spheres.py in topic parts

The spheres' words, one table or one social mechanic per part (Token-saving step 5, 10-18). These parts are the source.
`python3 -B build.py earth` (the Library's build.py, in the shared folder) joins them in name order, byte for byte,
into ../earth_spheres.py, which the game reads. Edit a part here, never the joined file. 00-head.py lists the tables.
